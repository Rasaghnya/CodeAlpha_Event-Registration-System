# Event Registration System

A full-stack Event Registration System built using Django and Django REST Framework.  
This project allows administrators to manage events and students, while authenticated users can register for events securely using token-based authentication.

## Features

- User Authentication & Authorization
- Token-Based Login System
- Student Profile Management
- Event Creation & Management
- Event Registration System
- User-Specific Registrations
- Cancel Registrations
- Protected REST APIs
- Django Admin Panel

## Tech Stack

- Python
- Django
- Django REST Framework
- SQLite
- HTML
- CSS
- JavaScript

## API Functionalities

- View all events
- View single event details
- User login with token authentication
- Register for events
- View logged-in user registrations
- Cancel registrations

## Authentication

This project uses Django Token Authentication for secure API access.  
Authenticated users receive a token which is used to access protected endpoints.

## Admin Functionalities

- Create and manage students
- Create and manage events
- Monitor registrations
- Manage authenticated users
